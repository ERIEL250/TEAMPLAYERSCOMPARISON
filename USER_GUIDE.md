## Getting Started

### Installation
1. Open the application in your web browser
2. Select a competition from the dropdown menu
3. Choose your home and away teams
4. Start building your lineup!

### Quick Start
- **Select Teams**: Use the team selection dropdowns to pick your favorite teams
- **Build Lineup**: Drag and drop players from the squad onto the football pitch
- **Save Lineup**: Click "Save Preset" to store your lineup for later

## Core Features

### Team Selection
- Browse competitions from top leagues around the world
- Search and filter teams by competition
- View team crests and basic information

### Lineup Building
- Choose from multiple formation options (4-3-3, 4-4-2, 3-5-2, etc.)
- Drag and drop players to their positions
- Get real-time formation validation feedback
- View player cards with detailed information

### Squad Management
- View all available players for selected teams
- Filter players by position
- See player ratings and statistics

## Lineup Management

### Saving Lineup Presets
1. Build your desired lineup
2. Scroll down to the "Saved Lineups" section
3. Click "Save Current Lineup"
4. Enter a name for your preset
5. Click "Save" to store it

### Loading Saved Presets
1. Go to the "Saved Lineups" section
2. Find the preset you want to load
3. Click "Load" to apply it to the current view

### Deleting Presets
1. Find the preset you want to delete
2. Click the "Delete" button
3. Confirm the deletion when prompted

### Exporting/Importing Presets
- **Export**: Click "Export Presets" to download all saved lineups as a JSON file
- **Import**: Click "Import Presets" and select a previously exported JSON file to restore lineups

## Sharing Lineups

### Sharing via URL
1. Build the lineup you want to share
2. Click the "Share" button in the header
3. The share URL will be automatically copied to your clipboard
4. Send this URL to anyone you want to share the lineup with

### Opening Shared Lineups
- Simply paste the shared URL into your browser's address bar
- The application will automatically load the shared lineup
- You can then modify, save, or export the shared lineup

---

## Dark Mode

### Enabling Dark Mode
- Click the sun/moon icon in the header
- The application will toggle between light and dark mode
- Your preference is automatically saved for future visits

## Troubleshooting

### Common Issues
1. **Players not loading**: Check your internet connection and refresh the page
2. **Formation invalid**: Make sure you have the correct number of players in each position
3. **Presets not saving**: Ensure localStorage is enabled in your browser settings
4. **Share link not working**: Make sure the URL was copied completely

### Support
If you encounter any issues, please check the GitHub repository for updates or open an issue.
